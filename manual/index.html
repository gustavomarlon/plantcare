01 — APRESENTAÇÃO

Sobre o PlantCare

O PlantCare é um aplicativo desenvolvido para ajudar no gerenciamento dos cuidados com plantas. A proposta é organizar informações importantes e facilitar o acompanhamento da rotina de manutenção de cada planta.

O sistema permite cadastrar plantas, consultar suas informações, atualizar registros e acompanhar os cuidados necessários.

Objetivo: facilitar a organização dos cuidados com plantas, reunindo em um só lugar informações sobre rega, iluminação e fertilização.

Público-alvo

Pessoas que possuem plantas em casa, estudantes e usuários que desejam organizar melhor os cuidados com suas plantas.

04 — PREPARAÇÃO

Requisitos do sistema

Para executar e modificar o projeto, são necessários:

  • Computador com Windows, macOS ou Linux compatível com Flutter.
  • Visual Studio Code.
  • Flutter SDK e Dart SDK configurados.
  • Dependências do projeto instaladas.
  • Acesso à internet para os serviços Firebase.
  • Projeto Firebase configurado para a plataforma utilizada.

Ferramentas adicionais

Para executar o aplicativo em um dispositivo Android, também é necessário configurar as ferramentas do Android SDK e um dispositivo físico ou emulador compatível.

05 — INSTALAÇÃO

Como instalar e executar

1. Abrir o projeto

Abra o Visual Studio Code e carregue a pasta raiz do projeto PlantCare.

2. Instalar as dependências

Abra o terminal integrado do VS Code, na pasta do projeto, e execute: 

flutter pub get

3. Verificar a configuração

Para verificar o ambiente de desenvolvimento, execute:

flutter doctor

4. Executar o aplicativo

Com um dispositivo ou emulador disponível, execute:

flutter run
Importante: antes de executar o aplicativo, confira se a configuração do Firebase corresponde à plataforma escolhida. A configuração para Android não garante, sozinha, que o aplicativo funcionará na Web.
06 — ARMAZENAMENTO

Estrutura do banco de dados

O Cloud Firestore organiza os dados em coleções e documentos. Neste projeto, as plantas de cada usuário ficam associadas à sua identificação de autenticação. 

usuarios/
  {uid}/
    plantas/
      {plantaId}/
        nome
        especie
        fotoUrl
        intervaloRegaDias
        ultimaRega
        iluminacao
        frequenciaFertilizacaoDias
        ultimaFertilizacao

        historico_regas/
          {registroId}

        historico_fertilizacoes/
          {registroId}

Descrição dos campos

  • nome: nome dado à planta.
  • especie: espécie da planta.
  • fotoUrl: endereço da imagem, quando utilizado.
  • intervaloRegaDias: intervalo previsto entre regas, em dias.
  • ultimaRega: data da última rega.
  • iluminacao: condição de iluminação indicada para a planta.
  • frequenciaFertilizacaoDias: intervalo previsto entre fertilizações.
  • ultimaFertilizacao: data da última fertilização.
Os históricos são armazenados em subcoleções. Os campos efetivamente gravados em cada registro dependem da implementação do aplicativo.

Segurança dos dados

As regras do Firestore devem restringir a leitura e a escrita aos usuários autenticados e aos respectivos dados. As regras publicadas devem ser revisadas sempre que a estrutura do banco for modificada.

08 — OPERAÇÕES

Como utilizar o sistema

Cadastrar uma planta

  1. Entre no aplicativo com sua conta.
  2. Acesse a tela inicial.
  3. Abra o formulário de cadastro.
  4. Preencha os dados solicitados.
  5. Salve o cadastro e confira se a planta aparece na lista.

Consultar uma planta

  1. Localize a planta na lista principal.
  2. Abra os detalhes para consultar suas informações.

Editar uma planta

  1. Abra os detalhes da planta.
  2. Selecione a opção de edição.
  3. Altere os campos necessários e salve.

Excluir uma planta

  1. Abra os detalhes da planta.
  2. Selecione a opção de exclusão.
  3. Confira a confirmação antes de concluir.

Registrar cuidados

Na tela de detalhes, utilize as opções de registrar rega ou fertilização para atualizar a data do cuidado e armazenar o respectivo histórico, conforme a implementação do aplicativo.

09 — MANUTENÇÃO

Como modificar o projeto

Alterar as cores

Localize o arquivo responsável pelo tema visual do aplicativo e modifique as cores utilizadas pela interface. O caminho exato deve ser confirmado na estrutura atual do projeto.

Alterar o nome do aplicativo

Verifique o nome configurado no código e as configurações específicas de cada plataforma. A alteração do título dentro do Flutter não muda, necessariamente, o nome exibido pelo sistema operacional.

Adicionar uma tela

  1. Crie o arquivo da tela na pasta apropriada do projeto.
  2. Implemente a interface e os comportamentos necessários.
  3. Configure a navegação a partir da tela que utilizará o novo recurso.
  4. Execute e teste o aplicativo.

Adicionar um campo ao cadastro

  1. Adicione o campo ao modelo da planta.
  2. Atualize os métodos de conversão para mapa e de leitura do Firestore.
  3. Inclua o campo no formulário, com a validação necessária.
  4. Confira as telas de detalhes e edição.
  5. Teste a leitura e a gravação dos dados.

Gerar uma versão Android

Para gerar um APK de lançamento, execute no terminal:

flutter build apk --release

O arquivo costuma ser gerado em build/app/outputs/flutter-apk/app-release.apk. Confira a saída do terminal para confirmar se a compilação terminou com sucesso.

10 — SOLUÇÃO DE PROBLEMAS

Problemas comuns

Dependências com erro

Execute flutter pub get no diretório raiz do projeto e confira as mensagens do terminal.

Aplicativo não inicia

Execute flutter doctor, confira o dispositivo selecionado e leia a mensagem completa de erro.

Erro de conexão com Firebase

Confira a configuração da plataforma, a inicialização do Firebase, a autenticação e as regras do Firestore.

Dados não aparecem

Verifique se o usuário está autenticado, se o caminho dos documentos está correto e se as regras permitem a operação.
